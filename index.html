🔄 Automatische Synchronisation

Automatisches Update: Dieser Fork wird täglich um 2:00 UTC automatisch mit dem Original-Repository synchronisiert.

Die Daten werden in folgender Reihenfolge aktualisiert:

  • main Branch: Empfängt Updates vom Original-Repository (PokemonTCG/pokemon-tcg-data)
  • release Branch: Wird automatisch mit dem main Branch zusammengeführt
  • GitHub Pages: Wird automatisch vom release Branch deployed

📝 Branch-Struktur

Wichtig: Bitte beachte die Branch-Struktur bei Contributions!
  • main: Hauptbranch, synchronisiert mit upstream
  • release: Stabiler Branch für GitHub Pages Deployment
  • feature/*: Für neue Features oder Änderungen

Pull Requests sollten gegen den main Branch erstellt werden.
