## Zweck

Panel-Dokumentation für Set-/Stats-/Search-/Community-Bereiche.

## Status

Ein dediziertes Runtime-Modul `js/ui/panels.js` ist aktuell noch nicht separat vorhanden. Panel-Logik liegt derzeit verteilt in `app.js`, `social-ui.js` und UI-Helfermodulen.

## Geplante Zielstruktur

- Einheitliche Panel-Factory pro View
- Entkoppeltes Show/Hide-Routing
- Konvergierte Events statt direkter DOM-Kopplung
